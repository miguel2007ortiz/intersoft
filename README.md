## 📖 Descripción

InterSoft es una plataforma SaaS de gestión empresarial desarrollada como proyecto del programa ADSO del SENA.

Su objetivo es ayudar a pequeñas y medianas empresas a administrar de forma sencilla sus procesos de:

- 📦 Inventario
- 💰 Ventas POS
- 🛒 Tienda Virtual
- 👥 Clientes
- 📊 Reportes
- 🤖 Inteligencia Artificial
- 🔒 Seguridad y Auditoría

---

# 🎯 Objetivo

Desarrollar una plataforma moderna que permita digitalizar los procesos de las MiPymes colombianas mediante una solución segura, escalable y fácil de utilizar.

# ⚙ Instalación

Clonar el proyecto

```bash
git clone https://github.com/miguel2007ortiz/intersoft.git
```

Entrar al proyecto

```bash
cd intersoft
```

Instalar dependencias

```bash
npm install
```

Ejecutar

```bash
npm run dev
```
