# Backend

Este directorio contiene la lógica del servidor y la gestión de datos.

## Estructura
- **core/**: Contiene la lógica principal de la aplicación.
- **cuentas/**: Manejo de cuentas de usuario.
- **intersoft/**: Funcionalidades específicas de Intersoft.
- **templates/**: Plantillas HTML para generar respuestas.

## Requisitos
- Asegúrate de tener todas las dependencias listadas en `requirements.txt`.
